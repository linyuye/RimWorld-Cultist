# Cultist — 密教模拟器扩展 Mod（RimWorld 1.7）

将《密教模拟器（Cultist Simulator）》的九大相性、漫宿入梦、密教结社、具名追随者、防剿局通缉与大小胜飞升线完整融入环世界 1.7（需 **Ideology** DLC）。  
A RimWorld 1.7 (**Ideology** required) expansion bringing *Cultist Simulator*'s nine Aspects, interactive Mansus dream exploration, secret societies, named followers, Suppression Bureau raids, and Long / Apostle victory lines to the Rim.

- **Steam 创意工坊 / Steam Workshop**: https://steamcommunity.com/sharedfiles/filedetails/?id=3845153052
- **GitHub Releases**: https://github.com/linyuye/RimWorld-Cultist/releases

## 核心内容 / Key Features
- **九大相性教团与秘传体系 / Nine Aspects & Tier 1–7 Lore**：灯、铸、杯、刃、冬、心、蛾、启、秘史完整 1–7 阶秘传书籍、古语研读与赞助人委托。
- **漫宿入梦与交互地图 / Interactive Mansus Map**：从林地、白门、牡鹿门、蜘蛛门直至孔雀门，支持原版风格漫宿地图选门与三选一翻牌。
- **差异化秘传装备 / Differentiated Occult Gear**：9 大相性服饰与 7 把特色武器（2 把近战重锤/匕首 + 5 把远程秘传武器）。
- **门徒晋升与总部圣所 / Exalted Disciples & HQ Sanctuaries**：高阶门徒专属相性能力与随机秘传词条；5 种教团总部特质。
- **长生者小胜 & 使徒大胜 / Minor & Major Victories**：长生者飞升/留世双结局、同存档换人再立新教，以及灯/铸/杯三线使徒大胜与守护具名者。

## 安装方法 / Installation
1. 确保已安装并启用 **RimWorld 1.7** 与 **Ideology** DLC。 / Requires **RimWorld 1.7** and **Ideology**.
2. 通过 Steam 创意工坊订阅，或从 Releases 下载解压并将 `Cultist` 文件夹放入 `Mods/` 目录。 / Subscribe on Steam Workshop or extract `Cultist` into your `Mods/` folder.
3. 在模组列表中将本 Mod 排序在 `Ideology` 之后启用即可。 / Place after `Ideology` in your mod load order.
