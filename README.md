# Cultist — 密教模拟器扩展 Mod（RimWorld 1.7）

将《密教模拟器》的九大相性、漫宿入梦、密教结社、具名追随者、防剿局通缉与大小胜飞升线完整融入环世界 1.7（需 **Ideology** DLC）。

## 核心内容
- **九大相性教团与秘传体系**：灯、铸、杯、刃、冬、心、蛾、启、秘史，完整 1–7 阶秘传书籍、古语研读与赞助人委托。
- **漫宿入梦与交互地图**：从林地、白门、牡鹿门、蜘蛛门直到孔雀门，支持原版风格漫宿地图选门与三选一翻牌。
- **差异化秘传装备**：9 大相性服饰与 7 把特色武器（含 2 把近战重锤/匕首 + 5 把远程秘传武器）。
- **门徒晋升与总部圣所**：晋升至高阶门徒可获得专属相性能力与随机秘传词条；5 种风格迥异的教团总部特质。
- **长生者小胜 & 使徒大胜**：支持长生者飞升/留世双结局、同存档换人再立新教，以及灯/铸/杯三线使徒大胜与守护具名者。

## 安装方法
1. 确保已安装并启用 **RimWorld 1.7** 与 **Ideology** DLC。
2. 将 `Cultist` 文件夹放入游戏 `Mods/` 目录，或在创意工坊订阅。
3. 在游戏模组列表中将本 Mod 排序在 `Ideology` 之后启用即可。
